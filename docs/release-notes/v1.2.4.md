# Zruxr 1.2.4: downloads that finish the job

Downloads used to stop at a file in your Downloads folder. Now they go where you want, unpack themselves, and show up in your library. And you're no longer limited to Pixeldrain.

## What's new

**Pick where it goes.** Press **Download** and choose the host and the folder. Games save inside Zruxr's own folder by default; change it for one download, or make a new folder your default.

**Unpacks itself.** `.rar` and `.zip` downloads are unpacked in the background (the launcher stays smooth, even on multi-GB archives), with progress on the button. The folder is tidied up, and the archive is removed once it has unpacked cleanly.

**Lands in your library.** The game's `.exe` is found and added automatically, named so cover art is found. No more Scan PC after every download.

**More hosts.** Gofile, FileKeeper, BuzzHeavier, FuckingFast and MediaFire now work alongside Pixeldrain. Their pages open in a panel inside the launcher with a line telling you what to press ("Press Download and wait"; on FileKeeper, the button under the main Download button). If a popup is blocked you get a big orange warning. The download then carries on in your Downloads list.

**Choose your host.** The Download dialog lists every host a game has, best first. Switch host from the panel if one isn't working. Sites that make you solve captchas (DataNodes, AkiraBox, Fikper and similar) are no longer used.

**Sorting.** The Downloads page can be sorted by name, size or date, and the games that were wrongly hidden (no Steam cover, or "patch"/"demo" in the title) are back.

**Clearer updates.** "New version available" now shows as soon as an update is found, and Settings has an **Updates** row with **Check now**.

**Fallbacks that work.** If a page won't continue in the panel, **Open in browser** opens it normally, and **I downloaded it** lets you pick the file you saved: it's moved, unpacked and added like any other download.

## Safety

- The host panel is sandboxed, has its own cookies, and can only visit public web pages (never your PC or home network).
- Pop-ups to other sites are blocked, and unexpected program downloads from ads (`.msi`, `.scr`, `.apk` and similar) are refused.
- Archives can't write outside their own folder when unpacking.
- A `.exe` that comes from a web page is never added to your library automatically.

## Before you update

- Your sources are refreshed automatically once. Games that only have links on removed captcha hosts will disappear from the list.
- The default download folder is now `%APPDATA%\Zruxr\Games`. Existing downloads stay where they are.
- Windows SmartScreen may warn about an unknown publisher because the app isn't code-signed. Choose **More info**, then **Run anyway**.

## Known issues

- Downloads from file hosts are in **beta**. Some may refuse to continue inside an embedded page: use another host, **Open in browser**, or **I downloaded it**.
- Only `.rar` and `.zip` are unpacked. `.7z`, `.iso` and multi-part RARs are downloaded but left for you to extract.
- If an archive only contains an installer, nothing is added: run it, then use **Scan PC**.
- A page download can't resume after a restart; **Retry** reopens the page.
