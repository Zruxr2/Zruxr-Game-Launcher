# Zruxr 1.2.5: the right .exe, every time

A fix for downloads adding the wrong program to your library, and help for games that won't start.

## What's new

**"Game won't start?" help.** If a game closes within 20 seconds (and you didn't press Stop), or can't start, Zruxr now says so and offers **Change .exe** and **Show folder**. Some games open through a launcher that closes by itself, and then this is fine. A tip under your library also explains it.

**Change .exe in one click.** Press **Edit** on a game and you'll see the other programs found in its folder, best first. Click one to switch, or press **Browse**.

## What's fixed

**Editing a game after a restart.** Renaming a game or changing its cover was silently ignored until you picked its file again. Fixed.

**Wrong .exe after a download.** Finished downloads used to pick the biggest program in the folder, so a large config tool, updater, launcher or bonus-folder program could be added instead of the game. Downloads now use the same picker as **Scan PC**, which:

- skips helper programs (config, updater, UnRAR, trainers, benchmarks, crash reporters, installers) and extras folders (Tools, Server, Editor, Bonus, Crack and similar);
- prefers a program whose name matches the game, even when the download's title is messy;
- picks Unreal's real `-Win64-Shipping.exe` instead of the small stub in the root folder;
- only uses a "Launcher" program when nothing better exists.

If it still picks the wrong program, open the game, choose **Edit**, and click the right `.exe` in the list. Please also open an issue with the game name and the two programs involved so the rules can be improved.
