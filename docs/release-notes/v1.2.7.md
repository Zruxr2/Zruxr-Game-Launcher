# Zruxr 1.2.7

## New
- **New startup screen.** An animated logo and loading bar when Zruxr opens.
- **Downloads page redesign.** Flatter, plainer look: bare covers, text tabs for sections, a thin Download button.
- **Hover panel on Downloads.** Hover a game to see a description, genres, banner and 3 screenshots from Steam.
- **Simple FileKeeper view.** On FileKeeper links, only the "click here" link shows once the page's countdown ends. Turn it off in Settings.
- **Copy debug info** button in the download panel, for reporting problems.

## Friends
- Block list.
- Invite a friend to play.
- Busy and Invisible status.
- Profile cards with colour, top games and total hours.
- Compare games with a friend.
- "Friends are playing" row in the Library.
- Notifications when a friend adds you, invites you, or starts a game you own.

## Helpers
- **Game won't start?** One-click checks for missing Visual C++/DirectX, blocked files and more.

## Before you update
- Using Friends? Run `docs/friends-setup-2.sql` once in the Supabase SQL Editor (after `friends-setup.sql`) to turn on the new friend features.

## Known limitations
- Downloads are in beta. If one fails, try another host or **Open in browser**.
- Game descriptions and screenshots come from Steam, so games it doesn't list show none.
- **Gentler auto-update.** Waits until Zruxr has finished opening, pauses while a game runs, and installs more cleanly.
