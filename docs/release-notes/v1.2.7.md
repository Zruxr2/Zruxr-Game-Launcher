# Zruxr 1.2.7

- **New startup screen.** An animated logo and loading bar when Zruxr opens.
- **Simple FileKeeper view.** On FileKeeper links, only the "click here" link is shown once the page's countdown ends. Turn it off in Settings.
- **Hover panel on Downloads.** Description, genres, banner and screenshots from Steam.
- **Friends upgrade** (run `docs/friends-setup-2.sql` once). Block list, invite to play, Busy/Invisible, profile cards, compare games, and a "Friends are playing" row.
- **Notifications** when a friend adds you, invites you, or starts a game you own.
- **Game won't start? helper.** One-click checks for missing Visual C++/DirectX, blocked files and more.
- **Copy debug info** button in the download host panel.
- **Downloads page redesign.** Flatter, plainer look.
